# Build and configuration

The build output is a static SPA. There is no CI/CD pipeline or deploy script in this repository: build with `pnpm build` and serve the `build/` folder from any static host (history API fallback to `index.html` is required because the app uses `BrowserRouter`).

## 1. Build

- `pnpm build` = `lint` + `clean` + `tsc` + `vite build`. Output goes to `build/` (gitignored). `pnpm preview` serves it locally.
- Assets are written with hashed names to `build/static/{js,css,media}` (`assetFileNames` / `chunkFileNames` / `entryFileNames` in `vite.config.ts`). `node_modules` code is split into a `vendor` chunk.
- `index.html` scripts, stylesheets and modulepreload links get subresource integrity (SRI) hashes from the local `sri()` plugin in `vite.config.ts` (sha512).
- Build-time globals injected by `vite.config.ts`:

| Global | Value |
|---|---|
| `__VERSION__` | `package.json` version |
| `__COMMIT_HASH__` | Short git commit hash (`unknown` if git is unavailable) |
| `__BUILD_DATE__` | ISO build timestamp |
| `__BUILD_ENV__` | `NODE_ENV` |

- In production builds `__REACT_DEVTOOLS_GLOBAL_HOOK__` is disabled.
- The demo needs `mockServiceWorker.js` at the site root (it is copied from `public/` into `build/`), and the page must be served from `localhost` or HTTPS for service workers. The file is generated by `npx msw init public` (see `msw.workerDirectory` in `package.json`) and must not be edited; after upgrading `msw`, run the command again.
- Vite aliases: `assets`, `components`, `contexts`, `core`, `pages`, `strings`.
- `vite-plugin-eslint` also lints during the dev server and build.
- SCSS deprecation warnings that come from EUI or old syntax are silenced in `css.preprocessorOptions.scss.silenceDeprecations`.
- `resolve.dedupe` and `optimizeDeps.include` keep a single copy of `react`, `react-dom`, `three` and `@react-three/fiber`. Do not remove them: two copies break react-three-fiber hooks ([architecture.md](architecture.md) chapter 12).

## 2. Configuration

- There are no environment variables and no deployment secrets: the app is self-contained, and the dev server needs no proxy.
- The dev server runs on port 15160 and opens the browser.
- Do not commit `.env.local` or `.env.*.local` (gitignored). If a `VITE_*` variable is ever added, note that its value is bundled into the client code, so it must not hold a secret.
